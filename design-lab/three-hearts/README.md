# Three hearts / 三颗红心

2026-10-29 · `codex/logo-three-hearts` · design exploration

Three identical heart contours rotated by 120°, using the current red, gold and circuit-board palette. The flat gold card frame stays the same.

- **01 / 向外开花**: outward points, inward heart notches. Closest to the current three-point flower, with a sharper silhouette.
- **02 / 三心相聚**: inward points. A more literal three-heart symbol.
- **03 / 旋心**: outward hearts with a local rotation. A more energetic, asymmetric petal contour within threefold symmetry.

Open `design-lab/three-hearts/index.html` from the repository's local HTTP server. Select a mark and compare the lockup, card backs, player colors, monochrome silhouette and 16–48 px sizes. The top button separates the petals for inspection; it is a construction view, not a final logo variant.

`marks.js` is the source for all experiment vectors. Run `node design-lab/three-hearts/export.cjs` to regenerate the nine standalone SVGs in `assets/`.

Production logos and shared components are unchanged. This branch is for visual review before any coordinated brand migration.
