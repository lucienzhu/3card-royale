三角梅牌花将深圳意象与普通扑克结合。保留既有牌框、三片同形120度旋转的苞片，以及每片一枚小金花心。

| 用途 | 色值 |
| --- | --- |
| 三角梅红／固定Logo红 | `#D83B74` |
| 花心金／固定Logo金 | `#DEB04A` |
| 纸白 | `#F7F7F2` |
| 薄荷青绿 | `#86D8C7` |
| 晚风底色 | `#111F2C` |

Logo红金在明暗中完全相同，背景、边框与功能文字按对比度适配。金色只作小面积点缀；年轻感来自平涂、留白、薄荷与蓝灰环境。它们是设计意象，不是官方城市色或人群调研结论。

Logo与字标作为一个对齐的单元，不要大标志与标题各自争夺注意力。界面用系统字体，牌值用Arial／Helvetica齐线数字，让2—10与JQKA同一基线。状态不能只靠颜色区分。

0.3.8的共用花牌只需一个集中提示；历史版仍保留各人的花牌。空伤区可以收起，但区域用途和操作应在牌区导览中可发现。

明确当前主要动作，完整规则按需展开，打开帮助不能丢选牌。简中用深圳花牌，英文用3Card Royale；翻译要区分小局与整场升级。

原创素材沿用MIT。自定义emoji PNG供支持上传的平台使用，不是通用Unicode字符；极简标志不构成唯一性或植物写实声明。
