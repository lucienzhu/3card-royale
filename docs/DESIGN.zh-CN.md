# 设计语言

[English](DESIGN.md) · [视觉识别](https://lucienzhu.github.io/gk-royale-playtest/brand.html?lang=zh-CN)

一张牌、一朵花、两个人；其余是纸与墨。三角梅牌花把深圳意象和一副普通扑克连在一起：三片同形、各转 120 度的苞片，每片一枚小金蕊。标志是一张平涂的金牌——没有金属光、没有纹理——牌背就是这张牌，花牌也是这张牌加一个角标。

| 名字 | 用途 | 色值 |
| --- | --- | --- |
| 红花 | 花、你的身份、主要按钮、选中态 | `#C5416B`（黑底上的小字用 `#E38BA6`） |
| 白鹭 | 昼的底：页面 `#F6F7F6`、牌桌 `#ECEEED`、浮层 `#FFFEFA`；夜里的字 | `#F6F7F6` |
| 黑盘 | 夜的底：页面 `#121417`、牌桌 `#1A1D21`、浮层 `#24282D`；昼的字 `#2A3331` | `#121417` |
| 金牌 | 标志、牌背、花牌：金底 `#ECCE80`、金边 `#A17C35`、金蕊 `#F2CD5D` | `#ECCE80` |
| 对手金 | 对手的花、苞片和藤上的标记；写字用 `#866300`（昼）／`#E4C46A`（夜） | `#AD7F0B` |
| 绿板 | 只用于品牌与网站，不进牌桌 | `#16765F` |

红花和金牌在明暗两个主题里完全相同；只有底色和功能文字按对比度切换。它们是设计意象，不是官方城市色或人群调研结论。

牌是一个组件：白纸面、墨色或红花色的角标。牌值用 Archivo 800 的十三字形子集（OFL），花色是写进牌里的内联 SVG，宽度是牌值的 0.66，和牌值排成一列；"10" 单独收窄。落在牌桌上的牌（进攻、防守、伤牌）同一个尺寸、平贴无影；手里的牌更大，并带一层投影。花牌的花是右下角的半透明水印，和其他牌的花色水印同一个角。

界面用系统黑体；字标用思源黑体 Bold（中文）与 Archivo（英文），已描边为 SVG。圆角只有三档：4、8、16。按钮两种：红填充、墨色下划线。换牌目标每个区域一个红色 ⇄ 圆标。伤势是名字旁的数字加五片苞片，苞片用身份色填充。状态不能只靠颜色区分。

标准 1.0 的共用花牌只需一个集中提示；历史版本仍保留各人的花牌。明确当前主要动作，完整规则按需展开，打开帮助不能丢选牌。简中用深圳花牌，英文用 3Card Royale；翻译要区分小局与整场升级。
