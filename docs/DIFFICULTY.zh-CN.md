# AI 对手

[English](DIFFICULTY.md) · [完整评测](experiments/complete-baseline/README.md)

入口：**设置 → 偏好 → AI 对手**。

| 对手 | 策略 |
| --- | --- |
| 简单 | 最多比较 64 个合法出牌；从牌堆换牌 |
| NN AI | 自回归 256 → 128，模仿 SDK Code AI |
| 困难 · Code AI | 原版牌桌策略，权衡出牌、保留组合与换牌 |
| Godlike | 可见对手当前手牌的搜索策略 |
| 竞技场 AI | 注册的 JavaScript、ONNX 策略，包括整手评分模型 |

新玩家默认简单。切换对手从下一次 AI 决策生效，不重新发牌。NN 加载或推理失败时提示并回退到简单；Godlike 失败时提示并回退到困难。其它规则变体沿用原来的 Code AI；上述选项适用于标准规则 1.0。

NN 是实验策略，不保证强度介于简单和困难之间。整手评分、自回归共用同一完整动作协议；模型及训练见 [MODEL.zh-CN.md](MODEL.zh-CN.md)。

## 当前评测

每格 1,000 小局：同一组 500 个种子，交换座位、平衡先攻，从 2 级开始。网页 **Code AI** 是困难档；**SDK Code AI** 是固定训练教师，二者不是同一个策略。

| 策略 | 对 Code AI | 对 SDK Code AI |
| --- | ---: | ---: |
| 随机 | 0.0% | 0.0% |
| 简单 · 64 | 34.1% | 35.6% |
| SDK Code AI | 48.0% | 自身 |
| 整手评分 · 256 → 128 | 42.6% | 45.5% |
| 自回归 · 256 → 128 | 23.9% | 26.6% |
| Godlike · 明牌 | 67.0% | 67.5% |

同条件神经网络评测中，自回归对简单胜率 **36.6%**，对 256/128 整手评分模型 **28.8%**。难度名称不代表策略强弱排序，也不预测真人胜率。Godlike 有额外信息，不参与公开信息天梯。

[19,000 局评测及延迟](experiments/complete-baseline/README.md) · [11,000 局神经网络对照](experiments/neural-baselines/README.md)。两套记录重合 4,000 局，不能相加当作独立样本。记录包含种子、哈希、环境与复现命令。

## 简单：有限候选

- 进攻：不放回抽样最多 64 个合法出牌，用 SDK 基线的比较方法选出最好的一手。
- 防守：存在不立即输局的应对时，先排除致命应对，再抽样比较。
- 换牌：每次用低优先级牌从牌堆抽换，不主动换对手的牌。

它能识别牌型和即时危险，但可能漏掉更好的组合，不按玩家胜率放水。抽样由公开观察确定，用 FNV-1a + xorshift32，不消耗发牌 RNG。相同观察得到相同动作。

64 是比较后选择的经验参数，不是最优值。8 张手牌有 56 种三张组合；伤牌和合法四炸、五炸会增加候选。[选型记录](experiments/difficulty-v1/evaluation.json)参与了这个决定，不是独立测试；上面的当前评测使用另一组种子。

[JS](../sdk/easy-policy.js) 与 [Python](../python/threecard_royale/easy_policy.py) 实现在相同观察上做一致性检查。

## 困难：原版牌桌策略

困难调用 `Game.aiStep()`，权衡进攻强度、防守伤害、剩余组合和换牌收益。换牌包括盲换对手手牌、公开伤牌及牌堆抽换。不读取暗牌，不搜索后续回合。SDK 训练教师是另一个较简单的策略。

回归检查覆盖 100 局、2,550 次相同决策，含 572 次换牌，其中 262 次盲换；切换难度不改变存档或发牌 RNG。另有 3,000 个开局状态与接入 NN 前的引擎一致。

## Godlike：当前手牌优势

可见双方当前手牌、伤牌和正在比较的牌。不读取牌堆顺序、弃牌、种子、RNG 或对局历史。

- 进攻：遍历合法三张及四／五张炸弹，再比较对手全部合法回应，选最坏回应下评分最好的一手。
- 防守：比较当前进攻下的所有合法应对；能避免的致命伤害优先排除。
- 换牌：比较一步期望收益，每次换完重新判断。盲换仍按规则随机抽取。
- 不记牌：假想抽牌只排除当前手牌、伤牌与出牌；不会从弃牌历史推算牌堆。

“最好”仅相对于当前启发式评分，不保证整局最优，也不穷举连续两次换牌。它在独立 Worker 中运行，失败时提示并回退到困难。当前胜率见上表；Node Worker 延迟不是手机延迟。

```sh
node tests/code-policy-regression.cjs
node tests/easy-policy.cjs
node tests/godlike-policy.cjs
```
