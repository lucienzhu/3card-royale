# 1.2.1 · Japanese, Korean and Spanish

Standard Rules remain **1.0.0**. The action protocol, policies, checkpoints and evaluation records are unchanged.

- Five-language picker across the playtest and GitHub Pages site: 简体中文, English, 日本語, 한국어 and Español.
- Localized practice, first-game hints, settings, table controls, replay, results and PNG share layouts.
- Translated About, Identity, Arena, hand research, Design System and all eight full-rule chapters.
- Language-aware navigation, document metadata and persistent preferences. Switching languages preserves the live game and user names.
- Shared translation catalog, placeholder checks and [maintenance documentation](../I18N.md).

The downloadable A4 PDFs remain Chinese/English; other locales label the English download explicitly. Research artifacts and API identifiers retain their original language.

Validation includes the existing JavaScript/GameCore/Arena suite, localization tests, desktop and mobile-sized browser checks, language cycling and the complete two-play practice in the three added languages. Browser checks use Chrome viewport emulation, not physical phones. No benchmarks were rerun for this localization release.
