# 1.2.0 · Unified actions and policy baselines

Standard Rules remain **1.0.0**.

- JavaScript policies, whole-move scorers and autoregressive networks share the `actions-v2` protocol: fixed card IDs, complete semantic moves and optional six-token serialization.
- Gym and browser inference use the same complete-action validation. Existing candidate-scoring checkpoints remain available through adapters.
- Built-in NN AI uses the autoregressive checkpoint. Whole-move scorers, including the 256 → 128 and 512 → 256 models, remain playable through Arena AI.
- Arena presents one baseline table, a seven-policy leaderboard, and three preset observation/action examples. Both training routes include reproducible collection, PyTorch training, TensorBoard curves and ONNX export.
- Homepage, Identity, Design System, GitHub introductions and bilingual blog content are aligned with the approved flower mark and current policy interfaces.

## Evidence

The complete benchmark contains 19,000 games; the additional neural comparison contains 11,000, including 4,000 shared records: **26,000 distinct games**. Both neural checkpoints are behavior-cloning baselines. The autoregressive model's 23.9% win rate against browser Code AI is below the whole-move scorer's 42.6%; a shared protocol does not imply equal playing strength.
