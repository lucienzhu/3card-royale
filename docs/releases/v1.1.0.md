## Play and contribute

- The bilingual Arena lists Elo, overall win rate, game count and measured p95 decision latency. “Play” selects the same registered artifact in the game; it is also available in Settings → Preferences → Difficulty → Arena.
- `policies/entries/<id>/` holds a manifest, a self-contained JavaScript module or ONNX model, and a README. The browser and local evaluator verify SHA-256 and use the same public observation / legal-action contract. Artifacts are capped at 5 MB.
- Python and other source languages are welcome: use Codex / Claude Code to port code to JS, then compare saved reference decisions. Neural policies can export ONNX. The porting guide and parity checker accompany the template.
- Policy PRs are reviewed and evaluated locally. The maintainer commits the season report; GitHub Pages hosts the leaderboard and playable artifacts. Browser games never change official Elo.

## First season

Five public-information policies, ten pairs, 200 independent small games per pair:
**2,000 games**, 800 per entrant. Both seats and first attackers are balanced.
All games start at levels `[2,2]`; Elo is anchored to Code AI at 1500.

| Policy | Elo | Wins / games |
| --- | ---: | ---: |
| Code AI | 1500 | 578 / 800 |
| SDK Code AI | 1374 | 511 / 800 |
| NN · 256 → 128 | 1306 | 485 / 800 |
| Easy · 64 | 1275 | 426 / 800 |
| Random | 502 | 0 / 800 |

These are this season's results against the whole field, not the historical
single-opponent NN benchmark. Elo depends on the pool and schedule; the report
includes the exact paired games, engine / policy / evaluator hashes and runtime.
Godlike does **not** enter the ladder. Its existing optional game difficulty remains.

The original Hard difficulty, dealing algorithm, GameCore implementations, rules
and deployed NN weights have not changed. The Arena Code adapter uses the original
heuristic with SDK canonical action ordering, documented separately from the
native table path and its historical statistics.

## Verification

- Existing product / rules / model / replay / onboarding / Godlike checks passed.
- Original Hard AI: all 2,550 decisions across 100 games still match the original,
  including 572 swaps and 262 blind swaps.
- Arena: manifest and checksum rejection; legal JS/ONNX outputs; public observations;
  seeded reset; original Hard/SDK action parity; worker timeout, cancellation,
  stale errors and invalid output handling.
- Elo recomputed from all records. Forty games replayed across every pairing with
  identical outcomes and final-state hashes.
- Browser checks exercise registered JS and ONNX policies, policy selection and
  Chinese/English desktop/mobile layouts. Viewport checks are not physical-phone
  performance measurements.

Workers improve responsiveness; they are not security sandboxes. Review submissions
before execution. Local evaluation aborts on an invalid action or timeout; web play
shows a fallback notice and continues with Easy AI.
