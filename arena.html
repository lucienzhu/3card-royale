评估方法与数据

标准规则 1.0，2 级开局。每组 500 个种子，交换座位、平衡先攻。表中各组全部正常结束，无非法动作。不同种子批次不合并；小幅胜率差异不足以证明策略强弱。

  • A · 整手评分、自回归与 Code AI：3,000 局，种子从 91,000,000 起。
  • B · 五种整手评分网络、Easy 和随机策略对 SDK Code AI，使用同一组种子。
  • C · Easy、SDK Code AI 与整手评分对 Code AI。整手评分 256 → 128 在此批次为 41.2% · 412 / 1,000；与 A 分开记录。
  • D · Godlike 对 Code AI：独立种子，可见对手手牌。

† Mac Chrome，单线程 WASM，220 个候选的推理 p95；不含编码。整手评分 256 → 128 在相同测量中为 1.10 ms。 性能记录

‡ Apple M1 / Node 22，单线程 WASM：整次 Worker 决策，含编码与全部推理调用，不含首次加载。两种延迟口径不可直接比较，均非手机测量。

Easy（64 候选）对 SDK 胜率 36.1%，对整手评分 256 → 128 为 44.1%。这组种子参与候选上限选择，非独立测试集。

整手评分数据含 252,859 次决策；自回归数据含 252,906 次。两者独立生成，按整局拆分训练、验证和测试。
