# 金花大乱斗 · 人机试玩

一副普通扑克牌的双人攻防游戏，网页中由自动对手与你对局。默认规则 0.3.3，界面修订 one-screen-3；每场随机开局，刷新继续当前存档，复盘种子留空即随机；可切换五个版本，各自保存在当前浏览器。

- 手机与桌面单屏牌桌，四区域点牌换牌。
- “规则介绍”提供开局、攻防结算、补牌与升级说明。
- “更多”可以开新局、设置种子、导出 JSON 试玩记录和查看牌型概率。
- 全部游戏逻辑在浏览器执行，无服务端、账户或 ChatGPT 依赖。

## GitHub Pages

在仓库 Settings → Pages 选择 Deploy from a branch，分支 main、目录 /(root)。本仓库只含静态网页，用 .nojekyll 跳过 Jekyll。

## 更新

替换 index.html 和 probability.html 后提交到 main。网页规则版本与导出记录中的版本应保持一致；存档按域名分别保存。
