# 金花大乱斗 · 人机试玩

一副普通扑克牌的双人攻防游戏，与自动对手对局。默认规则 0.3.3，界面修订 compact-table-2；每场随机开局，刷新续玩，复盘种子可选。支持五个规则版本，各自存档。

- 手牌叠放，伤牌独立成行；牌背与待补位保持正常长宽比例，手机、桌面和横屏可在一屏操作。
- 金色升级进度条突出整场目标：升到 A，再以 A 开局赢一局。
- “规则”介绍开局与结算；“菜单”提供新开局、版本、牌型、日志和导出记录。
- 伤牌全亮，5 伤败北，防守按胜出幅度换牌；本次只更新界面，规则、自动对手与概率数据保持。
- 沿用 compact 存档，刷新继续当前场；旧 UI3 存档仍单独保留。游戏完全在浏览器运行，无账号或 ChatGPT 依赖。
