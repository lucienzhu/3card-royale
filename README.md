# 金花拳 · 3Card Royale

一副普通扑克牌，双人攻防升级。网页提供人机试玩；中文简称花拳，English: 3Card Royale。菜单切换简体中文／English，语言独立于对局存档。

[开始试玩](https://lucienzhu.github.io/gk-royale-playtest/?version=0.3.6&lang=zh-CN) · [Play in English](https://lucienzhu.github.io/gk-royale-playtest/?version=0.3.6&lang=en)

默认规则0.3.6，界面counterplay-i18n-1。菜单保留0.3、0.3.1a、0.3.1b、0.3.2、0.3.3、0.3.4、0.3.5、0.3.6八版，分别存档；旧版规则保持。

- 各8张起手，伤牌全亮；通常出三张，也可出四张同点炸弹。自己的红桃级牌可逢人配，四炸6分、三炸5分，三四张可互接。
- 进攻胜按分差造成伤害；防守胜按分差获得手牌交换机会，同牌型点数胜为1。完全同型同点无事发生。
- 防守反击先点自己一张手牌，再点对手牌背盲换一张，或点牌堆弃旧摸新。两步提示与按钮均可操作；双方手牌保密，张数和伤势不变，伤牌不参与交换。
- 伤牌达到5张即输小局。双方各进攻一次后保留余牌、补到8张；小局赢家下局先攻，轮间仍交换先攻。
- 按终局伤势差升级，升到A后再赢一局夺冠。以A开局有三次机会：失败红灯、成功绿灯；三次失败仅该玩家回到2，对手保留等级。结算后开始下局清除旧三红灯。
- 极简共用进度线显示两人位置、等级差和A后终点；手机、桌面与横屏一屏操作，牌堆数量可视化、小局结算及夺冠特效保持。
- 首次与新场随机发牌；复盘种子选填，刷新续玩。游戏完全在浏览器内运行，无账号或ChatGPT依赖。

0.3.6完成40场程序完整升级、56组双语屏幕状态和实际点牌检查；程序不能替代真人体验。0.3.5各1000场完整升级先攻对照是独立实验。概率页保留三张组合的0.3.2／b数据，未计算四炸或新策略胜率。
