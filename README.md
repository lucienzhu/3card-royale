# 金花拳 · 3Card Royale

一副普通扑克牌，双人攻防升级。浏览器人机试玩，无账号或ChatGPT依赖。

[开始试玩](https://lucienzhu.github.io/gk-royale-playtest/?version=0.3.7&lang=zh-CN) · [Play in English](https://lucienzhu.github.io/gk-royale-playtest/?version=0.3.7&lang=en)

默认规则0.3.7，界面wound-counterplay-1；菜单保留旧八版，各自存档。

- 各8张起手，手牌保密，伤牌全亮。通常出3张，也可出四张同点炸弹；自己的红桃级牌可逢人配。四炸6 > 三炸5 > 同花顺4 > 同花3 > 顺子2 > 对子1 > 高牌0。
- 进攻胜按分差加伤；防守胜按分差得交换机会。同牌型点数胜为1伤／1机会；完全同点无事发生。
- 防守交换：先选自己的手牌或伤牌，再选对手盲手牌、对手公开伤牌、自己的另一牌区，或牌库。直接互换不抽牌；牌库选项弃旧摸新、原位补牌。每次1机会，手牌和伤牌张数都不变，不回血。换入伤区公开，手牌仍保密。
- 界面两步提示，可交换目标虚线高亮；点同牌取消，同来源牌区内改选，点击目标即完成一次。对手手牌随机盲抽，不看身份选择。
- 5伤即败小局。伤牌用后原位补明牌；每轮各进攻一次，中间不补手牌，轮末保留余牌补到8张。赢家下一局先攻，轮间仍交换。
- 按完整终局伤势差升级，升A后再以A开局赢一局夺冠。A开局失败亮红灯；三败仅该玩家回2，对手等级保留，成功亮绿灯并赢整场。
- 首次与新场随机发牌，复盘种子选填，刷新续玩。概率页仍为三张组合概率，未计算四炸或策略胜率。
